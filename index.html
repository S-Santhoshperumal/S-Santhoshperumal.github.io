Inside APEX

A Master Orchestrator coordinates five specialized agents. Select any agent to see what it does, or run an illustrative pass to watch a failure get healed and retried.

Uploaded test plan in, executed tests and report out.

Test planUploaded by the user
ReportResults, logs, screenshots

Retry loop. When a run fails, the Healer analyzes it and proposes a fix; the Orchestrator then retries execution.

apex run --illustrative
Press “Run the pipeline” to watch an illustrative run. The steps mirror how APEX works; the output is a demonstration, not a real test log.

How the Generator finds locators

Reuse what’s known, inspect the app for what isn’t.

  1. Check the Locator CatalogLook up the locators each test step needs.
  2. Found or missing?
    ✓ Found: reuse it from the catalog
    ? Missing: go to step 3
  3. Inspect with Playwright MCPOpen the application and identify the missing locator.
  4. Generate the scriptCombine the Planner’s structured test case, locator data and LLM context into a Playwright script.
